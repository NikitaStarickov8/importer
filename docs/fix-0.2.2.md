# Исправление 0.2.2: проверка справочников

Старая проверка прекращала импорт, если в любом месте справочника находилась неполная пара кода/описания или формула. Сообщение не указывало проблемную строку и могло создавать впечатление, что справочник ищется внутри шаблона.

В новой версии:

- Коды по-прежнему определяются по справочникам основной матрицы; в шаблоне допустимы только три штатных справочника.
- Посторонние неполные записи не мешают поиску известного корректного значения.
- Неполная запись, связанная с запрошенным кодом или описанием, блокирует импорт. Сообщение показывает источник, лист, строку и ячейки.
- При отсутствии соответствия показываются настроенные столбцы кода/описания и до трёх неполных строк для диагностики.
- Простые ссылки в справочниках поддерживаются без использования кэша Excel; сложные формулы не подменяются нулями.
- Повторное имя шаблона в сообщениях ошибок убрано.

Добавлено 11 проверок. Всего в проекте 50 автоматических проверок, включая случай шаблона с тремя справочниками и отличающимися значениями от основной матрицы.

Без самой рабочей книги пока нельзя определить, какая именно строка справочника вызвала исходную ошибку. Обновлённая диагностика показывает это на рабочем компьютере.

Для минимального обновления достаточно заменить app/importer.py и перезапустить программу.
