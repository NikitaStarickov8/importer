# Версия 0.2.3: точечные соответствия

Добавлена необязательная секция aliases в config.json. Пример: название «Флаг 66» в поле STOP_LIST_STATUS сопоставляется техническому коду MARKER_66; описание «Маркер 66» программа получает из основной матрицы.

Правила привязаны к полю и проверяются по используемому справочнику. Целью должен быть реальный код. Неоднозначные/отсутствующие цели, конфликт с существующей записью и ошибки формата конфига останавливают импорт с пояснением. Псевдонимы не подменяют обычный текст клиентских сообщений.

Конфиги без aliases совместимы с новой версией. Для существующей установки достаточно заменить app/importer.py и добавить aliases в свой config.json, сохранив остальные настройки.

Добавлены 10 проверок: соответствие и повторный импорт, регистр/пробелы, область действия, тексты сообщений, отсутствующая/неоднозначная цель, проверка технического кода, конфликт, старый конфиг и ошибки формата. Полный набор — 60 проверок.
