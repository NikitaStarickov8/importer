# Исправление 0.2.1: ссылки в шаблоне

При первом запуске на реальном шаблоне импорт останавливался на D3: «неожиданная формула». В D3 стоит обычная ссылка `=B3`; аналогичные ссылки используются в D4, D5 и D6.

Исправлено:

- Общие поля шапки читаются только при отсутствии соответствующих значений в строке.
- Простые ссылки на ячейки разрешаются непосредственно из исходных значений книги: относительные, абсолютные, на другой лист и цепочки ссылок.
- Кэш результатов формул не требуется. Исходный шаблон и формулы основной матрицы не изменяются.
- Циклические ссылки и неподдерживаемые вычисления по-прежнему останавливают импорт с указанием ячейки.

Добавлены восемь проверок, в том числе для D3–D6, заполнения из шапки, формул в строках, отсутствующего кэша, ссылок между листами и циклов. Полный набор — 39 проверок.

Для минимального обновления достаточно заменить app/importer.py и перезапустить python3 run.py. Полный архив дополнительно обновляет номер версии и документацию.
