# Версия 0.3.0: среда, версии, байпас, транзакции

При загрузке обязателен выбор ИФТ или ПРОМ. Изменяется только выбранная среда; разные среды запускаются отдельно. В CLI добавьте --environment IFT или --environment PROM.

Поиск выполняется среди активных строк выбранной среды. ИФТ-only запись для задачи ИФТ редактируется на месте. При PROM=1 и изменении создаётся новая версия; старая теряет только отметку выбранной среды, другая отметка сохраняется. Новая версия получает 1 только в выбранной среде. Реакция, текст и экранный заголовок — единственные изменяемые поля записи. При одинаковом содержимом ничего не меняется. Если активной записи выбранной среды нет, создаётся отдельная строка без изменения другой среды.

Байпас шаблона полностью игнорируется, даже если содержит ошибочную формулу или произвольный текст. Уже заполненный и пустой байпас существующих строк сохраняются. В новых записях и версиях байпас пустой; его нужно проверить вручную.

Пустой тип транзакции означает «Не финансовые операции». Технический код берётся из справочника основной матрицы, не придумывается. Значение применяется и при сопоставлении старых пустых строк, поэтому повторный импорт не создаёт дубли из-за пустой ячейки. «Финансовые операции» остаётся отдельным типом.

Для обновления остановите программу Ctrl+C. Из архива обновления замените папку app и файл run.py. Свой config.json не заменяйте: старые настройки совместимы. Файл examples/01_matrix.xlsx — обновлённая искусственная демо-матрица со справочником типов транзакций; замените его, если используете демо. Затем python3 run.py и обновите страницу браузера.

В результате «Добавлено строк» включает новые версии, их число отдельно указано в сообщении. «Изменено на месте» — число изменений ИФТ-only записей. Конфликты по-прежнему пропускаются с сообщением, остальные записи импортируются. Исходные файлы не перезаписываются.

Проверки: 95 автоматических тестов на Python 3.12 и 3.15, включая изоляцию сред, сохранность прежней версии/байпаса, повторные импорты, финансовые и нефинансовые типы, конфликты и скачивание через локальный HTTP-интерфейс. Синтетическая матрица 50 000 строк обработана за 18,75 секунды на компьютере разработки. Форма выбора среды и результат ПРОМ проверены в браузере. Рабочая матрица недоступна; первые запуски новой версии выполняйте на копии.
