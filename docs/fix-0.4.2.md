# Обновление 0.4.2 — английские ключи операции и подсистемы

## Установка

Остановите программу через Ctrl+C, замените папку app и run.py из архива. Свой config.json оставьте прежним. Запустите python3 run.py и обновите страницу через Ctrl+Shift+R. Вверху должна быть версия 0.4.2. Все предыдущие исправления включены в обновление.

## Правила

Для OPERATION_TYPE и SP_NAME главным является английский код. Если одному коду соответствуют несколько русских названий, берётся первое по порядку строк справочника основной матрицы, а не по алфавиту. Различные русские названия одного кода больше не являются конфликтом.

Код в строке имеет приоритет. Поддерживается также прежний формат, когда технический код помещён в столбец описания. Затем читается код шапки: D7/B7 для операции, D5/B5 для подсистемы. Если кода вообще нет, остаётся точный поиск русского названия. Опечатка или ошибка формулы русского названия не мешает известному английскому коду. Непрочитанную формулу D7/D5 можно обойти вручную заполненным B7/B5.

Неизвестный буквальный код по-прежнему останавливает импорт и не заменяется похожей операцией/подсистемой. Если у одного русского названия разные английские коды, но код не указан, выбор остаётся неоднозначным и требует ручного разбора.

## Защита результата

Если выбранное первое русское название также используется другим английским кодом, обратная формула INDEX/MATCH могла бы вернуть неверный код. Поэтому только в таких новых строках соответствующая ячейка SP_NAME/OPERATION_TYPE заполняется исходным английским кодом вместо формулы. При однозначном обратном соответствии формулы кодов сохраняются.

Русские описания новых строк задаются явно по первой записи справочника. Оформление и остальные формулы сохраняются. Существующие строки и справочники массово не переписываются; версии существующих строк сохраняют прежние ключи и описания. Если у старой строки код вычислялся по неоднозначному русскому названию и невозможно установить его без пересчёта, остаётся ручной разбор, а не угадывание.

ИФТ/ПРОМ, обязательные записи, исключение обычных разрешающих строк и частичного совпадения, байпас и трёхсекционный отчёт работают как раньше. Валидация остальных справочников не ослабляется.

## Проверки

Добавлены тесты для нескольких русских названий одного кода, физического порядка справочника, общих названий разных кодов, опечаток и ошибок формул SP_NAME, приоритета кода строки/шапки, неизвестных кодов, повторного импорта, продвижения в ПРОМ, сохранения остальных формул и HTTP-загрузки.
