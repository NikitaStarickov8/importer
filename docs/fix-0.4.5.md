# Обновление 0.4.5 — шапка операции и канал по платформе

## Установка

Остановите программу через Ctrl+C. Замените целиком папку app и run.py из архива обновления. Свой config.json сохраните. Запустите python3 run.py и обновите страницу через Ctrl+Shift+R. Вверху должна быть версия 0.4.5. Предыдущие исправления включены.

## Проверка операции

Сравниваются только B6 и D6 листа шаблона. Если оба названия заполнены и различаются, весь импорт останавливается до записи результата. В сообщении указаны файл, лист, обе ячейки и их значения. B4/D4 не сравниваются.

Регистр, неразрывные пробелы, пробелы по краям и повторные пробелы не учитываются. Простая ссылка D6 = B6 читается как значение B6. Пустое название не считается второй операцией. Для ошибки Excel или неподдерживаемой формулы русского названия сохраняется прежний переход к английскому OPERATION_TYPE; текст формулы не сравнивается с названием. Разные прочитанные B6/D6 блокируют импорт даже при известном английском коде.

## Канал по платформе

Если в строке шаблона заполнено SBOL_PRO_PLATFORM или SBOL_PRO_PLATFORM_DESCRIPTION, используем CHANNEL_INDICATOR = SBOL_PRO, а русское название берём из справочника основной матрицы («СБОЛ про»). Исходные код и описание канала шаблона, включая шапку, игнорируются. Ошибка формулы в игнорируемом канале не мешает импорту.

Сама платформа по-прежнему проверяется по справочнику. Неизвестная платформа вызывает ошибку. При пустой платформе канал читается по прежним правилам. Нормализованный канал используется для поиска, обновления, обязательных строк и продвижения в ПРОМ; повторная загрузка не создаёт дубли.

Правила применяются только к входящим шаблонам. Каналы и формулы существующих строк основной матрицы массово не исправляются. Прежняя логика обновлений ИФТ/ПРОМ сохраняется; исходный файл не перезаписывается.
