# Версия 0.3.2: полный итоговый отчёт по строкам

После обработки показаны номера затронутых строк Excel. Для добавления, изменения записи, создания ИФТ-версии и переключения отметок указано действие; старая и новая строки связаны номерами. Обычное значение первого столбца показывается дополнительно. Формулы CODE не пересчитываются и не подменяются номером строки.

В полном отчёте для каждой строки шаблона есть имя файла, лист/строка, статус, строки матрицы и причина:

- добавлена или изменена запись;
- добавлена ИФТ-версия / включена готовая строка в ПРОМ;
- без изменений — реакция, заголовок и текст совпадают либо нужная версия уже действует в ПРОМ;
- пропущена как повтор строки в загруженных шаблонах, со ссылкой на первый источник;
- пропущена на ручной разбор: неоднозначность, дубли, конфликт шаблонов, отсутствие готовой ИФТ-версии или несовпадение её содержимого.

Список действительно изменённых строк не смешивается с пропусками. Отчёт виден в браузере и скачивается кнопкой «Скачать отчёт .txt». Никакие дополнительные листы Excel и журналы на диске не создаются. CLI получает affected_rows, changes, outcomes и change_report в JSON; необязательное окно Tkinter показывает тот же текст.

Проверено 122 теста на Python 3.12 и 3.15: номера Excel, реальное значение первого столбца, формулы без кэша, ведущие нули текстовых кодов, перестановка столбцов, ошибки/пустые идентификаторы, изменения флагов старой/новой строки, неизменённые записи, повторы, причины ручного разбора, JSON и локальный HTTP-интерфейс. Бизнес-правила ИФТ/ПРОМ не изменены.

Обновление: остановить программу Ctrl+C, заменить папку app и run.py из архива, сохранить свой config.json, запустить python3 run.py и обновить страницу. Формат отчёта не требует дополнительных пакетов.
