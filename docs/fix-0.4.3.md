# Обновление 0.4.3 — служебные статусы без справочника

## Установка

Остановите программу через Ctrl+C. Замените папку app и run.py из архива. Свой config.json оставьте прежним. Запустите python3 run.py и обновите страницу через Ctrl+Shift+R. Вверху должна быть версия 0.4.3. Предыдущие исправления включены.

## Исправление

NORMAL («В стоп-листе не найден») и TECH_ERROR («Технический запрет») являются встроенными служебными статусами. Они больше не валидируются по справочникам «Статусы Стоп Листа» и COMPLIANCE_STOP_LIST_CODES. Соответствующих записей на справочных листах может вообще не быть. Программа не дописывает и не меняет эти справочники.

Это работает и для строк потребителя, и для автоматически сформированных обязательных строк. Узнаются английские коды и русские названия; написания «В стоп-листе не найден», «В стоп листе не найден» и «В стоплисте не найден» равнозначны. Существующие обязательные ИФТ-строки распознаются и без таких справочных записей, поэтому повторный импорт не создаёт дубли.

## Сохранение результата

У новых служебных строк явно записываются:

| Поле | Значение |
| --- | --- |
| STOP_LIST_STATUS | NORMAL или TECH_ERROR |
| STOP_LIST_STATUS_DESCRIPTION | В стоп-листе не найден или Технический запрет |
| BO_STEP_CODE_DESCRIPTION | NORMAL или TECH_ERROR |
| BO_STEP_CODE | пусто |
| STOP_LIST_STATUS_PRIORITY | 0 |
| STATUS_CODE | русское название служебного статуса |
| INFORMATION_SOURCE | SL |

В этих ячейках новой строки не остаются формулы, требующие отсутствующей записи справочника. Остальные формулы и оформление сохраняются. Старые строки и их формулы массово не исправляются и не переписываются.

Резолюция и её расчётные поля по-прежнему определяются по листу «Решения». Обычные статусы стоп-листа продолжают проходить прежнюю валидацию. Неизвестные обычные статусы не принимаются автоматически.

Правила ИФТ/ПРОМ не меняются: в ИФТ создаются недостающие записи, ПРОМ только включает готовые ИФТ-строки. Байпас, английские ключи операции/подсистемы и трёхсекционный отчёт работают как прежде.

## Проверки

Проверены импорт и автоматическое добавление при отсутствии служебных статусов в обоих справочниках, отсутствие зависимости от справочного листа для самих служебных значений, сохранность справочников, повторный импорт без дублей, продвижение в ПРОМ, варианты русского написания, пользовательские сообщения и полный HTTP-путь загрузки/скачивания.
