# Версия 0.2.4: конфликты на ручной разбор

Разные стопкоды в одной группе не считаются дублями. Реакция и сообщения обновляются только при единственном совпадении полного ключа.

Несколько подходящих строк матрицы: соответствующая строка шаблона не меняет матрицу и не добавляется заново. Неоднозначные строки шаблона и разные реакции для одного ключа в нескольких шаблонах тоже пропускаются. Остальные строки импортируются. Старые дубли остаются без изменений.

Старую строку, которую нельзя однозначно разобрать по справочникам, программа не считает отсутствующей. Если её возможные ключи пересекаются со строкой шаблона, эта строка шаблона направляется на ручной разбор. Например, неоднозначные «Кредитные карты» не мешают импорту другой подсистемы, если справочник позволяет исключить совпадение.

В браузере добавлены счётчик «На ручной разбор» и список причин с файлами/строками. CLI возвращает список conflicts в JSON. Результат всегда сохраняется отдельным файлом; исходники не перезаписываются. Ошибки структуры, неизвестные значения шаблона, конфигурация и запрещённые замены формул остаются блокирующими.

Обновление существующей установки: заменить папку app целиком, сохранить свой config.json, остановить программу Ctrl+C и запустить python3 run.py. Затем обновить страницу в браузере. Дополнительные пакеты не нужны.

Проверено 70 автоматических тестов на Python 3.12 и 3.15, включая HTTP-загрузку и скачивание результата с конфликтом. Синтетическая матрица на 50 000 строк обработана за 18,46 секунды на компьютере разработки. Интерфейс ручного разбора проверен в браузере. Рабочие файлы пользователя недоступны: реальную матрицу необходимо проверить локально на копии.
