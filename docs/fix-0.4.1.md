# Обновление 0.4.1 — операция по английскому коду

## Установка

Остановите приложение (Ctrl+C), замените папку app и run.py из архива. Свой config.json сохраните: настройки менять не требуется. Запустите python3 run.py и обновите браузер через Ctrl+Shift+R. Вверху должна быть версия 0.4.1. Обновление включает правила версии 0.4.0 и совместимо также с прежним config.json версии 0.3.2.

## Что изменилось

Для операции используем английский OPERATION_TYPE как главный источник. Русская опечатка, несовпадающее русское название или ошибка формулы OPERATION_DESCRIPTION не блокируют известный английский код. Новые записи получают правильное русское название из справочника основной матрицы. Ключи существующих записей и их описания массово не переписываются.

Приоритет источников:

1. Явный OPERATION_TYPE в строке.
2. Технический код в столбце OPERATION_DESCRIPTION (для совместимости с прежними шаблонами).
3. Английский код из шапки: D7, затем B7.
4. Только если кода нет — точный поиск по русскому названию строки, затем шапки при пустой строке.

Простые ссылки поддерживаются. Если кодовая ячейка содержит ошибку или непрочитанную вычисляемую формулу, можно использовать другой явно введённый английский код, например B7 вместо формулы D7. Сохранённый кэш INDEX/MATCH не используется. Формулы и ошибки русского названия не нужно вычислять, когда код известен.

Неизвестный буквальный код по-прежнему останавливает импорт: нельзя заменить его другой операцией по русскому названию или шапке. При отсутствии английского кода неизвестное русское название тоже остаётся ошибкой. Неоднозначные справочники направляются на ручной разбор. Если у нескольких кодов одно каноническое русское название, прежняя проверка безопасности формул INDEX/MATCH сохранена.

Изменение касается только операции. Валидация подсистемы, канала, типа клиента и других полей не ослабляется. Обязательные строки, пропуски, ИФТ/ПРОМ, байпас и трёхсекционный отчёт работают как в 0.4.0.

## Проверка

Добавлены тесты для опечаток, #N/A и сложных формул в названии, кодов в строке и шапке, D7=B7, невычисленной D7 с ручным B7, приоритетов источников, повторного импорта, отсутствующего/неизвестного кода и полного HTTP-пути загрузки/скачивания. Проверки выполняются на искусственных данных.
