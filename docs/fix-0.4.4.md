# Обновление 0.4.4 — английские коды формульных строк матрицы

## Установка

Остановите программу через Ctrl+C. Замените целиком папку app и run.py из архива, включая новый файл app/code_formulas.py. Свой config.json сохраните. Запустите python3 run.py и обновите страницу через Ctrl+Shift+R. Вверху должна быть версия 0.4.4. Предыдущие исправления включены.

## Исправление

Программа сравнивает английский код OPERATION_TYPE/SP_NAME из шаблона с английским кодом существующей записи. Ранее, когда код матрицы был формулой, программа переходила к поиску русского названия. При двух разных английских кодах одного русского названия это приводило к лишнему ручному разбору.

Теперь исходный английский код старой строки можно прочитать из:

- явно записанного значения;
- простой ссылки на ячейку;
- INDEX/MATCH (ИНДЕКС/ПОИСКПОЗ) с точным поиском 0, как на присланных снимках.

Поддерживаются ограниченные диапазоны и целые столбцы. Для поиска вида MATCH('Матрица решений комплаенс'!O:O, ...) используется значение O текущей строки. Учитываются именно лист и диапазон формулы, включая их начало и порядок строк, а не только общий справочник из config.json. Если совпадений несколько, читается первое, которое выбрала бы эта формула. Пробелы ключа не обрезаются, регистр при точном поиске не учитывается.

Если код шаблона отличается от вычисленного кода старой строки, одинаковое русское название их не объединяет. Для ИФТ создаётся запись своей английской группы, для ПРОМ по-прежнему нужна готовая ИФТ-версия. Код шаблона не подставляется вместо неизвестного кода матрицы.

## Сохранность файла

Чтение формулы не записывает её результат в ячейку, не заменяет формулу значением и не изменяет справочники. Исходный файл никогда не перезаписывается. В отдельном результате изменяются только добавляемые строки, изменяемые поля записей и отметки ИФТ/ПРОМ по прежним правилам. Новые версии могут получать переведённые формулы, но формулы существующих строк ради сопоставления не меняются.

Если изменений вообще нет, результат является побайтовой копией входного файла без пересохранения через openpyxl. Проверены неизменность контрольной суммы исходника, формул и данных существующих строк, справочников, а также точное совпадение файлов при отсутствии изменений.

## Ограничения

Это ограниченное чтение формул английского ключа, а не общий движок Excel. Неподдерживаемые функции и операции, внешние книги, приблизительный MATCH, wildcard-поиск, ошибки вычисления и отсутствующий результат требуют ручного разбора. Кэш значений Excel не используется, произвольные функции не исполняются. Поддержка не меняет валидацию остальных полей и не пересчитывает книгу целиком.

Проверки включают одинаковое русское название у разных английских кодов, оба результата сопоставления, конкретные диапазоны формулы, версионирование и ПРОМ, русские имена функций, повторный импорт и полный HTTP-путь.
