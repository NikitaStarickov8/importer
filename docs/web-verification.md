# Проверка браузерной версии 0.2

Проверено 28 октября 2026 года на локальном Mac.

- 31 автоматическая проверка: 21 для импорта и 10 для локального HTTP-интерфейса.
- Полный путь: загрузка матрицы и двух шаблонов, запуск импорта, получение результата, повторный импорт результата без дублей.
- Демо: 3 добавленные строки, 1 обновлённая, 1 без изменений.
- Проверены ошибки повреждённых файлов, неподдерживаемого расширения, незавершённой загрузки и неправильного размера.
- Проверен запуск по умолчанию при недоступном модуле tkinter.
- Сервер слушает только 127.0.0.1. Проверены отклонение чужих Host/Origin и требование сеансового токена для API.
- Проверены удаление временных данных при штатной остановке и сохранность исходных файлов.
- В браузере проверены открытие страницы, демо, выбор локальной матрицы и нескольких шаблонов, импорт и фактическое скачивание Excel-файла.

Все 31 локальная автоматическая проверка выполнена с Python 3.12.14 и Python 3.15. Проверка на рабочем SberOS с Python 3.13.5 остаётся на рабочем компьютере. В реализации используются стандартные модули Python 3.10+; cgi и Tkinter для браузерного режима не используются. Логика переноса и формулы не изменены в этой версии.
