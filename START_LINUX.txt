MatrixImporter 0.3.2 — запуск на Linux без Tkinter

1. Распакуйте весь архив в новую папку.
2. Откройте терминал в папке, где находится run.py.
3. Выполните:

   python3 run.py

4. Откройте адрес из терминала в браузере, обычно:

   http://127.0.0.1:8765

5. Для проверки нажмите «Запустить демо», затем «Скачать результат .xlsx».
6. Для своих данных выберите матрицу и шаблоны, обязательно укажите ИФТ или ПРОМ, затем «Импортировать».

Терминал оставьте открытым. Для завершения нажмите Ctrl+C.

Нужен Python 3.10+. Tkinter и права администратора не требуются.
Не запускайте через sudo и не устанавливайте дополнительные пакеты.
Все файлы обрабатываются на этом компьютере.

Результат откройте в Р7-Офис или Excel и дождитесь пересчёта формул.
После обработки доступен отчёт по всем строкам шаблонов, включая неизменённые и пропущенные с причинами. Его можно скачать отдельно как .txt.

Если окно браузера не открылось само — скопируйте адрес из терминала вручную.
Если порт занят — используйте тот адрес, который напечатала программа.
Для команды с --matrix, --templates и --output теперь обязательно добавьте --environment IFT или --environment PROM.
При обновлении замените папку app и run.py, свой config.json сохраните.
У старой версии снимается только отметка выбранной среды. Другая среда не меняется.
Задача ПРОМ только ставит PROM=1 готовой ИФТ-строке и снимает PROM с прежней версии; новые строки в ней не создаются.
Байпас не импортируется и требует ручной проверки. Новые строки получают пустой байпас.
