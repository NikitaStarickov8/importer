# MatrixImporter

Локальная программа на Python для переноса заполненных Excel-шаблонов в основную матрицу проверок. Версия 0.2 — браузерный интерфейс без Tkinter. Структура восстановлена по фотографиям, примеры искусственные.

## Быстрый запуск

На Linux откройте терминал в папке проекта и выполните:

```sh
python3 run.py
```

Или `sh Запустить.sh`. На Mac можно дважды нажать **Запустить.command**. На Windows используйте **Запустить.bat**.

Нужен Python 3.10 или новее. Tkinter, pip, права администратора и установка системных пакетов для браузерного интерфейса не требуются. Библиотеки Excel уже включены в `vendor`.

Браузер откроется автоматически. Если этого не произошло, откройте адрес из терминала вручную — обычно **http://127.0.0.1:8765**. Если порт занят, программа выберет свободный и напечатает другой адрес. Терминал оставьте открытым.

На странице нажмите **Запустить демо**, дождитесь результата и нажмите **Скачать результат .xlsx**. Ожидаемый результат: **3 добавленные строки, 1 обновлённая, 1 без изменений**.

Для обычного импорта выберите актуальную матрицу, добавьте один или несколько шаблонов и нажмите **Импортировать**. Затем скачайте готовую матрицу. Папка скачивания определяется настройками браузера.

Программа запускает сервер только на `127.0.0.1`: браузер передаёт файлы процессу Python на этом же компьютере. Интернет, внешний сервер и загрузка рабочих файлов в облако не используются. Все стили и скрипты включены в проект.

Файлы для обработки временно копируются в системную временную папку. До остановки программы доступны несколько последних результатов. Чтобы завершить работу, нажмите **Ctrl+C** в терминале; при штатном завершении временные копии удаляются. Закрытие вкладки само по себе процесс Python не останавливает.

За один импорт можно выбрать до 500 шаблонов, до 256 МБ на файл и до 512 МБ суммарно.

После импорта откройте результат в Р7-Офис или Excel, дождитесь пересчёта формул и сохраните файл. Сам Python не пересчитывает формулы. Поиск записей выполняется по исходным значениям и справочникам, поэтому повторный импорт работает и до пересчёта.

## Что делает программа

- Находит технические заголовки столбцов: буквы столбцов могут меняться.
- Принимает технические коды и русские описания, проверяя соответствие по справочникам основной матрицы.
- Обновляет поля существующих записей и добавляет отсутствующие.
- При добавлении копирует формулы и оформление образцовой строки, корректируя относительные ссылки.
- Расширяет диапазон Excel-таблицы, фильтра и подходящих диапазонов проверок/условного форматирования.
- Сохраняет отдельный новый `.xlsx`. Входные и существующие файлы не перезаписывает.
- Показывает число добавленных, обновлённых и оставшихся без изменений строк.

При конфликте двух шаблонов, неоднозначном совпадении, неизвестном коде или неверном формате импорт останавливается с указанием места ошибки. Весь пакет сначала проверяется, затем сохраняется.

## Как работает сопоставление

Ключ группы: `SP_NAME + OPERATION_TYPE + CLIENT_TYPE + CHANNEL_INDICATOR + RELATION_TYPE`; для `SBOL_PRO` дополнительно учитывается `SBOL_PRO_PLATFORM`. Соответствие участника операции полю `RELATION_TYPE` подтверждено.

Внутри группы строки различаются по `TRANSACTION_TYPE + INSPECTED_PERSON + STOP_LIST_STATUS + MATCH_NEGATIVE_CASE + MAX_AMOUNT`. Этот внутренний ключ пока принят для прототипа и требует сверки на реальной матрице. Порог суммы считается условием: изменение порога добавит новую строку. Различные типы совпадения или проверяемые лица не смешиваются.

Изменение поля ключа создаёт новую запись. Строки, отсутствующие в шаблоне, остаются в матрице. Деактивацию сотрудник выполняет вручную, снимая отметки IFT/PROM.

## Байпас и отметки окружений

Поле шаблона `Поле Байпас` переносится в `VALUE_SWITCH`:

| Шаблон | Основная матрица |
| --- | --- |
| пропуск контролей | пустая ячейка |
| запрет | ТЗ |
| пусто | пустая ячейка |

Правило значений подтверждено пользователем; целевой столбец `VALUE_SWITCH` принят по фотографиям. Если сотрудник использует другой столбец, поменяйте `bypass_target` в `config.json`. Значение «ТЗ» сохраняется с теми буквами, которые заданы в настройке.

IFT/PROM существующих строк сохраняются. У новых строк эти отметки и номер задачи (`Столбец1`) пока пустые, их заполняет сотрудник. Начальные значения можно изменить в `new_row_defaults`.

## Примеры

- `examples/01_matrix.xlsx` — матрица из четырёх строк и листов-справочников.
- `examples/02_template_update.xlsx` — обновление текста, неизменившаяся запись и новая строка с байпасом «запрет».
- `examples/03_template_new_group.xlsx` — две строки другой операции/платформы.
- `results/demo_result.xlsx` — результат проверочного импорта.

Все значения в примерах искусственные. Демонстрационные формулы повторяют зависимости рабочей матрицы, но используют обычные построчные ссылки и ограниченные диапазоны. Точные хвосты некоторых формул на фотографиях не видны. При работе с настоящей матрицей программа берёт её собственные формулы, а не формулы демо-файла.

## Командная строка

Из папки проекта:

```sh
python3 run.py --matrix examples/01_matrix.xlsx --templates examples/02_template_update.xlsx examples/03_template_new_group.xlsx --output results/my_result.xlsx
```

Windows: замените `python3` на `py -3`. Параметр `--config путь.json` позволяет использовать отдельную настройку.

Дополнительные параметры браузерного запуска:

```sh
python3 run.py --no-browser
python3 run.py --port 8877
```

Старое окно оставлено как необязательный режим `python3 run.py --desktop`; только для него нужен Tkinter.

## Проверки

```sh
python3 -m unittest discover -s tests -v
python3 tests/benchmark.py --rows 50000
```

Тесты работают на временных копиях. Нагрузочная проверка создаёт и удаляет искусственную матрицу, не затрагивая рабочие файлы.

## Перед первым рабочим использованием

Структура восстановлена по фотографиям. На рабочем компьютере нужно проверить внутренний ключ строки, целевой столбец байпаса и перенос на нескольких известных потребах в копии матрицы. Для такого теста не требуется выносить рабочий файл из корпоративного контура.

Форматы `.xls`, `.xlsb`, макросы `.xlsm`, защищённые файлы и неизвестные вычисления в полях шаблона в этой версии не поддерживаются. Фиксированные абсолютные диапазоны и уже сломанные ссылки в рабочих формулах сохраняются как есть. Сохранность корпоративных расширений, IRM и всех особенностей Р7 по фотографиям проверить нельзя.

## Структура проекта

- `run.py` — запуск браузерной страницы или командной строки;
- `app/importer.py` — чтение, сопоставление и запись;
- `app/web.py` — локальный сервер;
- `app/web_assets` — HTML, CSS и JavaScript страницы;
- `app/gui.py` — необязательное старое окно Tkinter;
- `config.json` — ключи, справочники и байпас;
- `docs/mapping.md` — соответствия полей;
- `tests` — проверки;
- `vendor` — openpyxl 3.1.5 и et_xmlfile 2.0.0 с лицензиями.
